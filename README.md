# LPC2148 Medicine Reminder System

## Project Overview
An embedded medicine reminder system developed using the LPC2148 microcontroller. The system helps users follow their medicine schedules by providing timely reminders through a buzzer and LCD display.

## Hardware Components
- LPC2148 Microcontroller
- Real-Time Clock (RTC)
- 16x2 LCD Display
- 4x4 Matrix Keypad
- Buzzer

## Development
- Embedded C
- ARM7 (LPC2148)
- RTC-based time scheduling
- Interrupt-based task handling
- LCD and keypad interfacing

## Key Features
- Medicine reminder scheduling.
- Real-time clock-based time monitoring.
- LCD display for user interaction.
- Keypad input for setting medicine schedules.
- Buzzer alert when a scheduled reminder is due.

## Project Objective
To develop a microcontroller-based reminder system that helps users remember their scheduled medication timings.
